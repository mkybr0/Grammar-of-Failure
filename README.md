This repository includes all the data processing and analysis for our Capstone Project "The Grammar of Failure", except that work which was completed in SPSS and STATA - to include the correlation matrix and the bivariate analysis. 
This work was conducted by Team 3 of the Class of 2026 of the Master of Science in Business Analytics at the University of Virginia's Darden School of Business and McIntire School of Commerce.

This work is sponsored by Guidehouse, Inc.

These files are uploaded from a Jupyter Lab repository, and large files were compressed to .csv.gz. 
Dependency pathways are updated, and some notebooks depend on these compressed files. All notebooks that output new csv files output them in .csv, not .csv.gz - even in cases where the notebook's output is intended to overwrite a .csv.gz input file.

The folders in this file are ordered sequentially according to the researchers' workflow. The folders' titles denote the purpose of the work performed within those folders.

The used as the primary input in 03_Analysis, "clean_data_7-9-26_9-47-PM.csv.gz" was produced as the final output  of the work flow contained in 02_Data_Cleaning. 
That final output is named "ASRS data - clean for working.csv.gz" in the Output_Files subfolder, but a copy was made on 7/9/2026, the date that researchers began their analysis, and renamed to denote the date and time of the last overwrite for the cleaned data.
